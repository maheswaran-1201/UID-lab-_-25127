HTML Tags — All Covered in PPT

Structure & Layout

<!DOCTYPE html>
Defines the document type and version of HTML being used.
<!DOCTYPE html>
<html>
Root element of every HTML page.
<html> ... </html>
<head>
Contains meta information about the HTML page (not visible on page).
<head><title>Page</title></head>
<title>
Sets the title of the HTML page (shown in browser tab).
<title>My Page</title>
<body>
Container for all visible content on the web page.
<body> visible content here </body>
<div>
Defines a division or section — used as a generic container for HTML elements.
<div style="color:red;">Content</div>
<link>
Used to connect external resources (like CSS files) to an HTML document.
<link rel="stylesheet" href="style.css">
<style>
Defines internal CSS styles within the HTML document's head section.
<style> p { color: red; } </style>

Text & Formatting

<h1> – <h6>
Heading tags — h1 is most important, h6 is least important.
<h1>Main Heading</h1>
<p>
Defines a paragraph. Always starts on a new line.
<p>This is a paragraph.</p>
<br>
Inserts a line break within text (self-closing tag).
<p>Line one<br>Line two</p>
<hr>
Creates a horizontal rule (line) to separate content sections.
<p>Para 1</p><hr><p>Para 2</p>
<b>
Makes text bold (purely visual).
<b>Bold Text</b>
<strong>
Makes text bold with semantic importance.
<strong>Important Text</strong>
<i>
Makes text italic.
<i>Italic Text</i>
<mark>
Highlights (marks) text with a background color.
<mark>Highlighted</mark>
<u>
Underlines the text.
<u>Underlined Text</u>
<del>
Strikes a line through deleted/removed text.
<del>Deleted Text</del>
<sub>
Displays text as subscript (below the baseline).
H<sub>2</sub>O
<sup>
Displays text as superscript (above the baseline).
x<sup>2</sup>

Media, Links & Embeds

<img>
Embeds an image in a webpage. Uses src and alt attributes.
<img src="photo.jpg" alt="Photo" width="300">
<a>
Defines a hyperlink. The href attribute specifies the link destination.
<a href="https://google.com">Google</a>
<iframe>
Embeds another webpage or external content (video, map, PDF) inside the current page.
<iframe src="page.html" width="600" height="400"></iframe>
<video>
Used to embed a video file on a web page.
<video controls><source src="movie.mp4"></video>
<audio>
Used to embed and play an audio file on a web page.
<audio controls><source src="song.mp3"></audio>
<source>
Specifies multiple media resources for <video> and <audio> elements.
<source src="movie.mp4" type="video/mp4">
<svg>
Container for SVG (Scalable Vector Graphics) — vector shapes drawn with code.
<svg width="200" height="100"> ... </svg>
<marquee>
Obsolete/deprecated tag used to create scrolling text or images. Not supported in HTML5.
<marquee direction="left">Scrolling Text</marquee>

Tables

<table>
Defines an HTML table with rows and columns.
<table border="1"> ... </table>
<tr>
Defines a table row inside a <table>.
<tr><td>Data</td></tr>
<th>
Defines a table header cell — text is bold and centered by default.
<th>Name</th>
<td>
Defines a table data/cell — regular and left-aligned by default.
<td>Siva</td>

Lists

<ul>
Creates an unordered (bulleted) list.
<ul><li>Item</li></ul>
<ol>
Creates an ordered (numbered) list.
<ol><li>Step 1</li></ol>
<li>
Defines each list item inside <ul> or <ol>.
<li>Coffee</li>

Forms

<form>
Used to create an HTML form for collecting user input.
<form action="page.php" method="post"> ... </form>
<input>
Most-used form element. Creates different input fields based on type attribute.
<input type="text" name="fname" placeholder="Enter name">
<label>
Adds a name/description to form inputs. Improves accessibility. "for" must match input "id".
<label for="name">Name:</label><input id="name">
<select>
Creates a dropdown/select list for users to choose one option.
<select name="branch"><option value="CSE">CSE</option></select>
<option>
Defines each selectable item inside a <select> dropdown.
<option value="IT">IT</option>
<textarea>
Creates a multi-line text input field (for comments, messages).
<textarea rows="5" cols="30"></textarea>
<button>
Defines a clickable button. Always specify the type attribute.
<button type="button" onclick="alert('Hi')">Click</button>
<fieldset>
Groups related form elements together with a visual box.
<fieldset><legend>Info</legend></fieldset>
<legend>
Defines a caption/title for the <fieldset> element.
<legend>Personal Info</legend>
<datalist>
Provides a list of pre-defined options for an <input> element (like autocomplete).
<input list="browsers"><datalist id="browsers"><option value="Chrome"></datalist>
<output>
Represents the result of a calculation (used with oninput events).
<output name="result" for="a b"></output>

All Definitions

Internet
The Internet is the biggest world-wide communication network of computers that connects computers all over the world, allowing people to share information and communicate from anywhere with an Internet connection. It has millions of domestic, academic, business, and government networks.
ARPANET (Advanced Research Projects Agency Network)
The first workable prototype of the Internet, created in the late 1960s. It allowed multiple computers to communicate on a single network.
TCP/IP (Transmission Control Protocol / Internet Protocol)
Developed by Robert Kahn and Vinton Cerf in the 1970s. A communications model that set standards for how data could be transmitted between multiple networks. ARPANET adopted TCP/IP on January 1, 1983.
World Wide Web (WWW)
Invented by Tim Berners-Lee in 1990. A collection of websites or web pages stored in web servers and connected to local computers through the Internet. WWW is an information system where documents are identified by URLs and interlinked by hypertext/hyperlinks.
Hypertext
A word or words that contain a link to other texts or a website. A hypertext document with its text and hyperlinks is assigned an online address called a URL.
Hyperlink
An icon, graphic, or text that links to another file. Web pages are connected by links called hypertext or hyperlinks and accessed using HTTP.
URL (Uniform Resource Locator)
An online address assigned to a web page or website. A particular collection of web pages belonging to a specific URL is called a website. Example: www.facebook.com
Web Server
A computer that runs websites. Its basic objective is to store, process, and deliver web pages to users using Hypertext Transfer Protocol (HTTP). It also supports SMTP (email) and FTP (file transfer).
HTML (Hyper Text Markup Language)
The standard markup language for creating web pages. HTML describes the structure of a web page using a series of elements that tell the browser how to display content.
HTML Element
Defined by a start tag, some content, and an end tag: <tagname>Content goes here...</tagname>
HTML Attributes
Additional information provided for HTML elements. Always specified in the start tag. Come in name/value pairs: name="value". Example: <tagname attribute="value">
CSS (Cascading Style Sheets)
Used to format the layout of a webpage (presentation). Controls color, font, text size, spacing, element positioning, background, and display on different screen sizes. CSS saves work — it can control the layout of multiple web pages at once. The word "cascading" means a style applied to a parent element also applies to all children elements.
Inline CSS
Applied to a single HTML element using the style attribute. Example: <p style="color:red;">
Internal CSS
Defines style for a single HTML page. Written in the <head> section within a <style> element.
External CSS
Defines style for many HTML pages. A separate .css file linked with <link rel="stylesheet" href="file.css"> in the head section.
SVG (Scalable Vector Graphics)
An XML-based markup language used to create vector graphics in web pages. SVG graphics are scalable and do not lose quality when zoomed or resized. They are resolution-independent, can be styled, animated, and manipulated with JavaScript.
iframe (Inline Frame)
An HTML element used to embed another webpage or external content (websites, YouTube videos, Google Maps, PDFs, documents, web apps) inside the current webpage.
CSS Box Model
A box that wraps around every HTML element consisting of four parts: Content (text/images), Padding (space around content, transparent), Border (surrounds padding and content), and Margin (space outside border, transparent).
CSS Float
A property that specifies how an element should float within its container, placing it on the left or right side, allowing text and inline elements to wrap around it. Values: left, right, none, inherit.
Responsive Web Design (RWD)
An approach to web development where a website automatically adjusts its layout, images, and content to fit different screen sizes and devices.
CSS Flexbox
A layout model for arranging items (horizontally or vertically) within a container in a flexible and responsive way. Used for one-dimensional layout (rows OR columns).
CSS Grid
A grid-based layout system with rows and columns that allows developers to create complex web layouts. Used for two-dimensional layout (rows AND columns).
CSS Transition
Allows the change of property values smoothly over a given duration (e.g., when hovering). Requires: the CSS property to animate and the duration of the effect.
CSS Transform
Modifies the appearance and position of an element without changing the actual document layout. Allows elements to be rotated, moved (translated), scaled, and skewed.
CSS Animation / @keyframes
CSS allows animation of HTML elements without JavaScript. @keyframes rule defines the stages of a CSS animation — how styles change at different points during the animation.
Version Control System (VCS)
A software tool that helps developers track changes in source code, manage different versions of files, collaborate with multiple developers, and restore previous versions when needed.
Git
A Distributed Version Control System (DVCS) used to track code changes, collaborate with teams, maintain project history, and revert to previous versions.
CSS Position Property
Defines how an element is placed in the document. Values: static (default – normal flow), relative (offset from normal position), fixed (relative to viewport), absolute (relative to nearest positioned ancestor), sticky (relative until scroll reaches it, then fixed).

CSS Transforms (translate, rotate, scale, skew)

}

/* Combining Multiple Transforms */

Questions & Exam-Ready Answers

Q
What is the Internet?
The Internet is the biggest world-wide communication network of computers. It connects computers all over the world, allowing people to share information and communicate from anywhere. It has millions of smaller domestic, academic, business, and government networks that carry many different kinds of information.
Q
What is ARPANET? When was it created?
ARPANET stands for Advanced Research Projects Agency Network. It was the first workable prototype of the Internet, created in the late 1960s. It allowed multiple computers to communicate on a single network.
Q
What is TCP/IP? Who developed it?
TCP/IP stands for Transmission Control Protocol and Internet Protocol. It was developed by scientists Robert Kahn and Vinton Cerf in the 1970s. It is a communications model that set standards for how data could be transmitted between multiple networks. ARPANET officially adopted TCP/IP on January 1, 1983.
Q
What is the World Wide Web (WWW)? Who invented it?
The World Wide Web was invented by Tim Berners-Lee in 1990. It is a collection of websites or web pages stored in web servers and connected to local computers through the internet. WWW is an information system where documents are identified by URLs and interlinked by hypertext/hyperlinks. It is like a huge electronic book whose pages are stored on multiple web servers across the world.
Q
What is a Web Server?
A web server is a computer that runs websites. Its basic objective is to store, process, and deliver web pages to users using Hypertext Transfer Protocol (HTTP). Apart from HTTP, it also supports SMTP (Simple Mail Transfer Protocol) for emailing and FTP (File Transfer Protocol) for file transfer and storage.
Q
What is HTML? List its features.
HTML stands for Hyper Text Markup Language. It is the standard markup language for creating web pages.

Features:
  • HTML describes the structure of a web page
  • HTML consists of a series of elements
  • HTML elements tell the browser how to display content
  • It uses tags like <h1>, <p>, <img>, etc.
Q
What are HTML Attributes? Give examples.
HTML Attributes provide additional information about elements. Key points:
  • All HTML elements can have attributes
  • Always specified in the start tag
  • Come in name/value pairs: name="value"
Examples: src (image source), href (link URL), alt (alternate text), style (inline CSS), id, class

What is the difference between colspan and rowspan?
  • colspan: The colspan attribute defines the number of columns a cell should span (merge horizontally). Example: <td colspan="2">
  • rowspan: The rowspan attribute specifies the number of rows a cell should span (merge vertically). Example: <td rowspan="2">
Q
What are the three types of CSS? Explain each.
  • Inline CSS: Applied to a single HTML element using the style attribute. e.g., <p style="color:red;">
  • Internal CSS: Defined in the <head> section using <style> tag. Applies to the single HTML page.
  • External CSS: Written in a separate .css file, linked using <link rel="stylesheet" href="style.css">. Controls multiple pages at once.

Q
Explain the CSS Box Model with its four components.
The CSS Box Model is a box that wraps around every HTML element. It has four parts:
  • Content: The actual data (text, images) inside the element
  • Padding: Clears transparent space around the content (inside border)
  • Border: A border surrounding the padding and content
  • Margin: Clears transparent space outside the border

Total element width = defined width + left padding + right padding + left border + right border + left margin + right margin
Total element height = defined height + top/bottom padding + top/bottom border + top/bottom margin

Q
What is CSS Transform? List all transform functions.
The CSS Transform property modifies the appearance and position of an element without changing the document layout. Transform functions:
  • translate(x, y) — Moves element horizontally/vertically
  • rotate(angle) — Rotates element clockwise/counterclockwise (in deg/rad)
  • scale(x, y) — Increases/decreases size
  • skew(x-angle, y-angle) — Tilts element along X or Y axis
  • transform-origin — Sets pivot point for transformation (default: center)
  • matrix() — 2D matrix transformation (takes 6 values)
  • matrix3d() — 3D matrix transformation (takes 9 values)
  • Multiple transforms can be combined: transform: translate(100px) rotate(30deg) scale(1.2);

Important Notes & Key Points

📌 History Timeline: ARPANET (late 1960s) → TCP/IP by Kahn & Cerf (1970s) → ARPANET adopted TCP/IP (Jan 1, 1983) → WWW by Tim Berners-Lee (1990)
📌 Heading Priority: <h1> = most important, <h6> = least important. Use h1 only once per page for SEO best practices.
⚠️ <marquee> is OBSOLETE: The <marquee> tag is deprecated and not supported in HTML5 standards. It was used for scrolling text but should not be used in modern web development.
📌 <th> vs <td>: Text in <th> is bold and centered by default. Text in <td> is regular and left-aligned by default.
📌 label "for" attribute: The "for" attribute of <label> must match the "id" of the <input> element for proper connection and accessibility.
📌 select with size attribute: The size attribute on <select> specifies the number of visible values in the dropdown.
📌 textarea uses rows and cols: rows = visible number of lines, cols = visible width in characters. Can also use style="width:200px; height:600px;"
✅ CSS Priority: Inline CSS > Internal CSS > External CSS (in terms of specificity, Inline overrides Internal and External)
📌 CSS Colors — Three Ways: (1) Named: color:red; (2) RGB: rgb(255,0,0); — values 0–255 (3) HEX: #ff0000; — format #rrggbb (00 to ff)
📌 HTML supports 140 standard color names
📌 float:left makes divs appear side by side — HTML <div> elements are block elements that take full width by default. float:left makes them appear next to each other.
✅ Flexbox vs Grid: Flexbox = 1D (row OR column). Grid = 2D (rows AND columns). Use Flexbox for nav bars, card rows. Use Grid for full page layout.
📌 justify-content vs align-items in Flexbox: justify-content controls horizontal (main axis) ↔. align-items controls vertical (cross axis) ↕.
📌 For margin: auto — Use margin: auto; with a defined width to horizontally center a block element. Without a width, center alignment has no effect.
⚠️ animation-duration is REQUIRED: If animation-duration is not specified, no animation will occur because the default value is 0s.
📌 position: relative required for animation movement: For top/left properties to work inside @keyframes, the element must have position: relative. position: static (default) ignores these properties.
📌 CSS Transition requires TWO things: (1) The CSS property to add effect to, (2) The duration of the effect.
✅ Git Basic Workflow: git init → git add → git commit → git remote add origin → git push → (git pull before next push) → git branch/merge
📌 SVG Important Attributes: width, height (container), fill (shape color), stroke (border color), stroke-width (border thickness). For circle: cx, cy (center), r (radius). For rect: x, y, rx, ry (rounded corners).
📌 1fr in CSS Grid = fractional unit. 3 columns of 1fr each means each column takes 33.3% of available space.
📌 grid-template-areas uses row-by-row string definitions. Repeating a name in the same row means that item spans that many columns. Each string = one row.
⚠️ datalist "list" attribute must match the "id" of the <datalist> element — exactly like label/input connection.
✅ transform-origin default is center. Change to left top, bottom right, etc. to control the pivot point of rotation/scale/skew.
📌 animation-direction values: normal (forward, default), reverse (backward), alternate (forward then backward), alternate-reverse (backward then forward)
📌 VCS Popular Tools: Git, GitHub, GitLab, Bitbucket, SVN. Git = most popular DVCS. SVN = popular CVCS.
